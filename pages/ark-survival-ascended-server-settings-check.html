Which server settings must I know before using a guide or calculator?

Direct answer

Any recommendation involving time, quantities, loot, creature strength, or progression must name the relevant server assumptions. Record the live settings and active mods first; otherwise an exact-looking answer can be precisely wrong for your world.

Decision signalWhat to verifyNext move

Mods alter systemsList active mods and load orderSeparate mod behavior from the base game

Decision checklist

  • Record difficulty, taming, breeding, harvest, and loot settings
  • List active mods and their versions
  • Identify which settings affect the current decision
  • Recalculate time and quantities using the live values
  • Recheck after server or official game updates

Stop and recheck when

  • Stop when the server cannot confirm a setting that controls the result
  • Do not transfer conclusions between servers with different rates or mods

Common mistakes

  • Treating official settings as universal
  • Ignoring a mod that changes the same system
  • Using old values after a server configuration update
