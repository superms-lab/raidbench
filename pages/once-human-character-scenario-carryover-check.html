What carries over, and should I reuse my character for the next scenario?

Direct answer

Do not decide from the word carryover alone. List each asset or unlock, identify whether it belongs to the account, character, server, or scenario, then confirm the current official rule for the transition you plan to make.

Decision signalWhat to verifyNext move
Asset mattersClassify it as account, character, server, or scenarioVerify the exact current transition rule
New scenario is attractiveCompare access, friends, and retained progressChoose the character path after dependencies are clear
Rule is ambiguousUse the latest official announcement and in-game noticeDelay irreversible choices until confirmed

Decision checklist

  • Name the source and destination scenario or server
  • List every item, unlock, and relationship that matters
  • Classify each one by account, character, server, or scenario
  • Check the latest official transition notice
  • Preserve screenshots of important state before moving

Stop and recheck when

  • Stop when current official wording does not cover the intended transition
  • Do not create or abandon a character to test an irreversible assumption

Common mistakes

  • Treating all progress as one category
  • Using an old season answer for a new scenario
  • Making the character decision before checking social and server dependencies
