Was the raid worth it?

Short answer

Start with resource break-even: recovered sulfur-equivalent value minus boom and lost kits. Then judge time, counter risk, and strategic value separately. A raid can be resource-positive but strategically poor, or resource-negative but worthwhile because it removed an immediate threat.

Checklist

  • Record estimated sulfur before the raid.
  • Record actual sulfur after the raid.
  • Estimate lost kits and consumables in the same unit you use for recovered loot.
  • Keep time and strategic value visible instead of hiding them in a made-up exchange rate.
  • Use the result to improve the next target-selection decision.

Example

If a raid uses 5,600 sulfur, returns loot you value at 7,000 sulfur equivalent, and loses a 1,000-equivalent kit, the resource result is +400. That is above resource break-even, but a long exposed raid can still be a poor use of wipe time.

Use two verdicts, not one

Record a resource verdict first, then a strategic verdict. Keeping them separate prevents a satisfying fight from disguising a material loss and prevents a defensive raid from looking pointless simply because the boxes were light.

  • Resource verdict: recovered value minus boom and losses.
  • Strategic verdict: threat removed, location secured, or future farming protected.

Common mistakes

  • Counting only loot and ignoring boom cost.
  • Ignoring failed attempts.
  • Assigning precise values to every item without stating the assumptions.
  • Calling a raid profitable without tracking actual spend.

Frequently asked questions

What counts as profit in a Rust raid?

For resource profit, subtract boom and lost-kit value from recovered loot value using your own stated conversion assumptions. Review time, counters, and strategic value separately.

How should I value guns and components?

Use the replacement or progression value on your server and at your stage of the wipe. Do not present one exchange rate as universal across servers, wipes, and group sizes.

Can a resource-negative raid still be worth it?

Yes. Removing a direct threat, protecting a farm route, or securing territory can create strategic value, but label that result separately from resource profit.
