POE2 0.4.0i build impact check

Which builds and boss situations are directly affected by the official 0.4.0i fixes, and which guides do not need a broad rewrite.

Does POE2 patch 0.4.0i make my build guide outdated?

Short answer

Patch 0.4.0i is a narrow fix set, not a broad balance pass. Recheck a guide if it depends on critical-hit chance after shapeshifting or if it discussed bosses failing to emerge with a stolen Proximal Intangibility modifier. Builds outside those cases do not become outdated solely because of this patch, although older patch and economy checks still apply.

AreaWhat it means
Direct build impactA shapeshifting critical-hit condition was fixed so it no longer depends on another shapeshift-tracking stat.
Boss impactSome bosses failing to emerge with a stolen Proximal Intangibility modifier were fixed.
Event supportThe patch added support for upcoming race events.
Cosmetic fixA Phoenix level-up effect trigger was corrected.
Broad balanceNo broad skill, passive, item, or economy rebalance is listed in 0.4.0i.

Player checklist

  1. Check whether the build uses shapeshifting and the named critical-hit condition.
  2. Remove any workaround that only existed for the fixed tracking bug.
  3. Re-test the affected damage condition in a controlled encounter.
  4. Do not label unrelated builds outdated from this patch alone.
  5. Continue checking the guide's original patch, required items, and economy assumptions.

What this update does not prove

The patch notes do not announce a general build rebalance, so unrelated skill trees and item priorities require their own evidence before being changed.

Refresh trigger
