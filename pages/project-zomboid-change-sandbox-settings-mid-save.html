Can I change zombie settings without abandoning my current save?

Direct answer

Treat a mid-save sandbox change as a migration, not a casual toggle. Duplicate the save first, record the current build and settings, change one variable in the copy, and verify both existing and newly loaded areas before trusting the result.

Decision signalWhat to verifyNext move
The world mattersConfirm the save and game build are backed upTest only on a duplicate
One setting is unclearChange one zombie variable at a timeCompare behavior before adding more edits
Existing areas differTest an explored area and a newly loaded areaKeep or roll back based on both results

Decision checklist

  • Record the current build number and sandbox values
  • Create a separate copy of the complete save directory
  • Make one controlled settings change in the copied world
  • Load an existing area and a newly visited area
  • Keep the original untouched until several sessions are stable

Stop and recheck when

  • Stop if the copied world fails to load or loses expected data
  • Roll back if the change affects more systems than the one being tested

Common mistakes

  • Editing the only copy of a long-running world
  • Changing several population variables in one test
  • Assuming existing cells and new cells must update identically
