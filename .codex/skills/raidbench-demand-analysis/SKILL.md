# RaidBench Demand Analysis

Use this skill only inside the RaidBench Agent pipeline.

## Inputs

Read only the case JSON and listed source artifacts. Do not browse, scrape, deploy, edit files, or contact communities.

## Output

Return only JSON matching `schemas/agents/demand-analysis.schema.json`.

## Rules

- Separate player pain from official marketing news.
- Favor repeated problems, decision anxiety, patch confusion, and expensive mistakes.
- Do not copy community text into recommendations.
- Do not recommend selling in-game currency, items, accounts, boosting, cheats, exploits, gambling, or top-ups.
- Mark uncertain source coverage as a limitation.
- The deterministic opportunity score in the input is locked and must not be changed.
